# Видео кодом — карта репозитория для Claude

Рабочее пространство для коротких роликов и моушн-дизайна кодом: кадр — функция времени на HTML/SVG (+ three.js для 3D),
рендер Playwright + ffmpeg. Навыки — в `.claude/skills/` (подхватываются сами). Пользователь — автор роликов; работай на его языке.

## Что где лежит

| Путь | Что это |
|---|---|
| `.claude/skills/short-script` | сценарии коротких вертикальных роликов: хуки, биты, хронометраж, лист для записи голоса |
| `.claude/skills/code-motion` | производство: движок, шаблон проекта, озвучка, музыка, сведение, рендер, автопроверки |
| `.claude/skills/social-account` | позиционирование, упаковка, публикация, слово в комментариях → личка, статистика |
| `.claude/skills/prompt-builder` | промпты для сессий производства и субагентов (критики, независимый оценщик) |
| `projects/<имя>/` | ролики пользователя — каждый отдельный проект code-motion (создаётся `zsh tools/new.sh <имя>`) |
| `inbox/<имя>/` | входящие материалы к ролику: ТЗ, макеты, запись голоса |
| `examples/` | 7 готовых роликов: код сцен, `script.json`, шрифты, 3D-ассеты (без звука и голоса) |
| `lab/` | 14 идей-образцов на том же движке (`lab/CLAUDE.md`) |
| `refs/` | чужие репозитории подмодулями-ссылками (`refs/README.md`, `repos.json`), исследования `refs/research/`, приёмы `ideas.json`, сайты ассетов `sites.md` |
| `library/` | звуки (Kenney CC0 и др.), `package.json` со шрифтами и иконками (`npm i`), каталог 3D со ссылками |
| `tools/` | `new.sh` новый ролик · `refs.mjs` скачать референсы · `refvideo.sh` + `refsheet.py` разбор чужого ролика · `font.mjs` шрифт с кириллицей · `takes.py` нарезка дублей голоса · `deess.py` диэссер |
| `LESSONS.md` | уроки семи роликов — прочитай перед первым роликом |

## Соглашения

- **Перед нетривиальной работой — план**: общая картина, решённое отдельно от открытого; исполнять после согласия пользователя.
- **Формула ролика** (подробно — `LESSONS.md`, навыки): массовая тема; хук-заявление с числом; 30–50 с; ответ на хук к 8–10 с;
  крупные подписи; в конце — польза «забери себе» и слово в комментариях → ответ в личку.
- **Производство — до ~3 ч** от «да» на сценарий до финала. Вместо кругов внутренних критиков — проверка фактов и **один
  независимый оценщик** (сначала 3–5 мин читает свежие гайды; отчёты и оценки ему закрыты; проход до 10 мин; отчёт до 20 строк:
  оценки 0–10, 3 сильных, 3 слабых, одна главная правка, прогноз). Итог ниже 8 — одна правка до публикации.
- Если пользователь сам просит критиков: проход до ~30 мин, отчёт до 25 строк, 2–3 визуальных параллельно по диапазонам сцен.
- **Арт-дирекшн** (время суток, палитра, настроение) — согласовать по 2–3 картинкам-ориентирам до стоп-кадров. Ночь с неоном и
  тёмный фон со свечением по умолчанию не брать — примета ИИ-роликов.
- **Сданные версии не перезаписываются**: каждая версия — новый файл (`v1`, `v2`…).
- **Лицензии**: у референсов поле `license` и `ok` в `refs/repos.json`; `ok: false` или «только смотреть» — код не берём, только
  идеи. Музыка — с лицензией или из библиотеки площадки при публикации.
- **Скрипты из `refs/repos/` не запускать**, только читать.
- **К каждому сценарию — лист для записи голоса** `<slug>.zapis.md`: главное слово фразы КАПСОМ, паузы `|`, интонация `↘` / `→`,
  ударения, памятка перед записью; по 3 дубля на фразу. Голос в публикацию — живая запись; клон — только черновики и пробы.
- **Голос после склейки дублей — через диэссер** `tools/deess.py` (мягко: `--pct 90 --max 6`).
- **Цифры за 72 ч** — до старта следующего ролика.
- Генерируемые файлы руками не править: `lab/ideas/registry.js`, `*/timing.js`, `*/code-data.js`, `refs/lock.json`.
