# vidIQ: стоит ли добавлять в конвейер «Кода и кадра» — 2026-10-23

Для автора. Проверка совета «используй бесплатное расширение vidIQ для анализа популярных идей и поиска футажей».
Сведения собраны 23.10.2026 по официальным страницам vidIQ, Chrome Web Store и сторонним обзорам; где источник
конкурент или рекламный блог, это помечено. Чего не нашёл, то «не подтверждено». Россия как рынок не рассматривалась,
русский здесь только язык запросов и роликов. Регистраций и установок не делал.

## Вердикт

**Брать для автора вручную, коротко и как пробу; в обязательный конвейер не включать.** Совет верен наполовину.

- «Поиск футажей» — путаница: у vidIQ ничего про футаж и стоки не найдено (см. таблицу, п. 4). Для нас это и не нужно.
- Выбросы, конкуренты, тренды — у нас уже есть через `yt-dlp` и свои расчёты (просмотры ÷ подписчики, ÷ медиана канала).
  Новое у vidIQ одно: **оценка объёма поисковых запросов на YouTube** (оценочная, не точная). Её `yt-dlp` не даёт.
- Главная неожиданность: у vidIQ есть **официальный MCP-сервер**, доступный и на бесплатном плане. Агентам не нужен
  браузер: подключение по OAuth, без нарушения правил площадок. Но кредитов на Free всего 150 в месяц.

### Как встроить
1. **автор, один раз, вручную (15 мин):** поставить расширение, открыть Chrome с обычным аккаунтом, проверить 5–10
   русских запросов из наших тем (например «токены ИИ», «0,1 + 0,2», «брахистохрона»). Смотреть: показывает ли vidIQ
   объём и конкуренцию именно по русским запросам и не пусто ли. Результат записать в `content/log.md` одной строкой.
2. **Только если объём по-русски есть:** автор подключает MCP (`claude mcp add --transport http vidiq https://mcp.vidiq.com/mcp`,
   затем `/mcp` и вход в vidIQ — интерактивно, агент сам войти не может). Подключение через аккаунт vidIQ, **канал YouTube
   подключать не нужно** для исследования (не подтверждено, что MCP требует канал; не подтверждайте разрешение «Manage your
   YouTube account»).
3. **Агенты:** вызывать `keyword_research` только для финалистов отбора тем (3–5 запросов на ролик, 5 кредитов каждый),
   передавать результат в `topics-evidence-*.md` отдельной колонкой «объём (vidIQ, оценка)». Потолок: 20 вызовов в месяц,
   остальное для `outliers` по дополнительной проверке. Перед каждой сессией проверять баланс (вызов бесплатный).
4. **Не делать:** не гонять агентов по расширению в браузере, не использовать vidIQ как единственное доказательство
   спроса (объём оценочный), не выбирать тему только по «Daily Ideas».

## Риски
- **Разрешение «Manage your YouTube account»** при подключении канала: шире, чем нужно для исследования. Канал подключать не надо.
  На канале «Код и кадр» это будет доступ к управлению видео и плейлистами, а при компрометации сервиса это риск.
- **Приватность расширения:** оно читает страницы YouTube (оверлей), собирает данные об активности; часть идентификаторов
  уходит рекламным сетям. Ставить в **отдельный профиль Chrome без личных входов**, не там, где открыты почта и банк.
- **Утечка бесплатности:** MCP заявлен «на ограниченное время» (формулировка заголовка). Конвейер не должен ломаться,
  если доступ станет платным: используем как необязательный источник.
- **Кредиты на Free тают быстро** (30 вызовов в месяц). Один экспериментальный прогон на 8 тем выжжет треть.
- **Оценки объёма без методики на русском:** можно принять пустое/заниженное число за «нет спроса». Проверяем вручную до подключения.
- **Расхождения в официальных лимитах** (6 или 8 результатов Outliers; цены MAX; расширение «в переходе на кредиты»):
  цифры на странице могут устареть, перед закупкой сверять в самом аккаунте.
- **Правила площадок:** автоматизация в браузере запрещена. Агенты ходят только через MCP (официальный вход), расширение
  использует человек.
- **Не подтверждено:** состав разрешений расширения в манифесте, независимые проверки безопасности, поддержка русского в данных.

## Что решить автору
1. Согласен ли на 15-минутную ручную пробу на русских запросах (отдельный профиль Chrome, канал не подключать)?
2. Если объём по-русски есть, подключать ли MCP к Claude Code (OAuth делает автор) и принять лимит 20 вызовов в месяц?
3. Платные планы ($199+/год) для нас не оправданы: см. вердикт, «Boost» не нужен, пока нет данных о ценности объёма по-русски.
