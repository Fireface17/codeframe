# Сайты: где брать ассеты и смотреть референсы

Список внешних сайтов для работы над роликами (собран 2026-10-21, без проверки лицензий).
Перед использованием чего-либо в ролике — открыть страницу лицензии на сайте: условия меняются,
у одного сайта бывают разные условия для разных файлов. Пометки «в окружении» — уже есть локально.

## Видео-стоки и звук
| Сайт | Что брать | Заметка |
|---|---|---|
| [Mixkit](https://mixkit.co) | стоковое видео, музыка, звуки, шаблоны | в ролики можно; раздавать файлы отдельно нельзя |
| [Pexels](https://www.pexels.com/videos/) | стоковое видео и фото | |
| [Pixabay](https://pixabay.com/videos/) | видео, музыка, звуки | |
| [Coverr](https://coverr.co) | короткие стоковые видео для фонов | |
| [Freesound](https://freesound.org) | звуки | у каждого файла своя лицензия: CC0 / CC BY / NC |
| [YouTube Audio Library](https://studio.youtube.com) | музыка и звуки без Content ID | раздел «Фонотека» в YouTube Studio |
| [Uppbeat](https://uppbeat.io) | музыка для роликов | бесплатный тариф с атрибуцией |
| [Kenney](https://kenney.nl/assets) | UI- и игровые звуки | CC0; **в окружении**: `library/sfx/kenney/` |
