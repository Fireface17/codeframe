# unslop-video — ролики без почерка ИИ

Цель — чтобы ролик узнавали как работу автора, а не как «ещё один ролик, сделанный нейросетью».
Модель по умолчанию выбирает среднее: тёмный фон со свечением, всё по центру, пружинку на каждом
появлении, «это не просто X — это Y». А при производстве серией появляется второй слой — **свой
шаблон**: общий движок, общие модули субтитров и одни и те же «удачные» ходы переходят из ролика в
ролик, и серия становится одним роликом в разных цветах. Скилл работает против обоих слоёв.

Работай на языке пользователя; по умолчанию — русский.

## Главные принципы (и почему)

1. **Шаблонна не примета, а выбор по умолчанию.** Штамп, маркер, жёлтый, тряска — допустимы, если выбраны
   под этот ролик и объясняются одной фразой. Поэтому на каждую находку ответ: «оставляю, потому что …»
   или «заменил на …». Шаблон узнают по сумме 3–5 признаков, а не по одному.
2. **Запрет без замены рождает новый шаблон.** Убрал свечение — модель найдёт следующий дефолт (гигантское
   слово, обрезанное краем; круговые шторки). Поэтому в каталоге у каждой приметы есть замена, а процесс
   начинается не с запретов, а с материала мира и референсов.
3. **Свой стиль — из темы и бренда, а не из библиотеки эффектов.** Материал мира берётся из того, из чего
   тема сделана в реальности (чертёж, чек, табло, экран игры); фирменный жест — из формы знака канала.
4. **Узнаваемость — постоянство немногих констант.** Несколько констант (знак, концовка, звуковая подпись,
   голос) повторяются без изменений в каждом ролике. Всё остальное — палитра, шрифт, движение, субтитры —
   выбирается заново. Обратная ошибка: сделать константой общий инфографический блок («число на плашке»,
   моно-сноска) — тогда константой становится сам шаблон.
5. **Строитель — не судья.** Автор ролика цитирует числа скриптов; «шаблонно или нет» решает свежий
   оценщик или человек.
6. **Не плодить кругов.** Если в рабочей папке есть правило «одна правка после оценщика», находки unslop входят
   в эту одну правку. Оценка оценщика ниже 4 — ничего не трогать ради «уникальности».

## Порядок работы

**Перед роликом (паспорт, ≤ 25 мин).** Прочитай язык канала, если он есть (например `content/brand/language.md`
в рабочей папке), и ★-приметы в `references/tells.md`. Заполни паспорт ролика `<проект>/unique.md` по шаблону из
`references/process.md` §1: материал мира → 3–5 референсов (поиск по базе: `node tools/find-refs.mjs "<тема>"`,
если есть) → правила в числах → 3 ограничения → характер движения и субтитров → фирменный жест + одно
странное решение → список отказов по умолчанию. Паспорт показывается автору вместе с 2–3 стоп-кадрами.

**Сценарий.** `node ~/.claude/skills/unslop-video/scripts/text.mjs <script.json | сценарий.md>` — русские маркеры ИИ-текста и речевые
привычки серии (тире, «Но» на 3–4-й фразе, анонсы с двоеточием, «одна X», финал-дилемма). Балл ≥ 4 —
переписать отмеченное, не меняя фактов. Пары «было → стало» — `refs/research/human-writing.md`, если есть.

**Перед сдачей.** `zsh ~/.claude/skills/unslop-video/scripts/check.sh <папка проекта> [ролик.mp4]` — все автопроверки и контактный лист:
- `text.mjs` — текст сценария;
- `code.mjs` — исходники сцен: шрифты, цвета, свечения, кривые, служебный текст, привычки движка
  (тряска, вечный дрейф камеры, доля пружин с перелётом, штампы, скотч, зачёркивания, маркеры, счётчики);
- `dom.mjs` — отрисованный кадр через `seek(t)`: шрифты на экране, подписи по углам, мелкий капс, служебный
  текст, призрачный текст, мелкий текст, «число + ярлык», число текстовых слоёв;
- `frames.py` — готовый MP4: доля тёмных кадров, вспышки, застывшие куски, ритм склеек, хвост, громкость.
Отчёт — `<проект>/out/unslop.md`. Потом свежий оценщик по листу — задание в `references/judge.md`.
Тесты глазами (подмена темы, без знака, серия, тишина, счёт громкого) — `references/process.md` §3.

Проверки требуют проекта на движке code-motion (`index.html` с `window.seek`, `window.FRAME`, Playwright
в `node_modules`); `text.mjs` и `frames.py` работают с любым текстом и любым MP4. На macOS с Homebrew перед
node: `export PATH="/opt/homebrew/bin:$PATH"`.

## Ответ пользователю
Коротко: балл каждой проверки, 3–5 главных находок с временем или файлом:строкой, для каждой — замена,
и что в ролике уже своё (не трогать). Не выдавай весь отчёт: путь к `out/unslop.md` достаточно.
