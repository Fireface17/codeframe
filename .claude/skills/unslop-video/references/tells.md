# Каталог примет «ИИ-ролика» и замен

Как читать: **примета** — как узнать · `авто` (какой скрипт ловит) → **замена**. ★ — нашли в своих роликах
(«Код и кадр», 11 роликов на 2026-10-29), это первое, что проверять. Один признак ничего не доказывает:
шаблон узнают по сумме 3–5. Любая примета допустима, если выбрана под этот ролик и объясняется одной
фразой («штамп — потому что ролик про суд»). Шаблонна не сама примета, а выбор по умолчанию.

Скрипты: `text` — text.mjs · `code` — code.mjs · `dom` — dom.mjs · `кадры` — frames.py · `глаз` — только оценщик.
Источники приметы — внешние ссылки и разбор своих роликов; полные отчёты в репозиторий не входят.

## 1. Цвет и свет
- **Почти чёрный фон «как дорого»** — у ИИ-роликов 6 из 10, у дизайнеров меньше трети · `кадры` (доля тёмных > 60 %) → фон от материала темы (бумага, асфальт, экран, металл); тёмное — только если тема тёмная.
- **Свечение, ореол, неон, туманность, боке, блик** · `code` (blur ≥ 8, drop-shadow ≥ 20 px, radial) → свет с источником (одно направление, спад, контактная тень) или тень-сдвиг без размытия; ореол — только в момент события (~0,3 с).
- **Фиолетовый/индиго/циан, неон из 5–6 цветов, градиент на фоне** · `code` (hex) → один акцент со смыслом + максимум один сигнальный.
- **Градиентный текст** · `code` → сплошной цвет; акцент — размером.
- ★ **Один и тот же акцентный цвет во всех роликах** (жёлтый в 10 из 11) · `глаз` по серии → акцент от предмета темы (цвет корпуса, игры, документа); фирменный цвет — знаку и одному главному моменту.
- ★ **«Таблоид» жёлтый + чёрный + красный** (3 ролика подряд) → двухцветная палитра с реального референса (обложка, упаковка, интерфейс темы).
- ★ **Молочный фон + чернила + один акцент + зерно** — дословно самый копируемый рецепт Opus-шоурилов (5 из 11) → фактура места действия, а не «бумага по умолчанию».
- ★ **Пастель Excalidraw** `#fceda3 #f7cbca #bff0c0 #afd7fb #cdc0fa` из дефолтов движка → палитра пипеткой с 2–3 картинок-ориентиров.
- **Свой плоский фон на каждую мысль** (> 3 за ролик = презентация) · `кадры`/`глаз` → один мир на акт, смена — склейкой или переносом объекта.
- **Тёмное ↔ светлое через серое или затемнение** → растущий объект или жёсткая склейка.
- ★ **Одинаковая мягкая студийная тень под каждым предметом** → жёсткий направленный свет, тени разной длины, местами без тени.

## 2. Шрифт
- **Шрифт-монокультура** (Inter, Roboto, Arial, Poppins, Montserrat, Space Grotesk, Geist, Syne, Playfair…) · `code`, `dom` → шрифт под тему с кириллицей; пары «акцидентный + моно» или «антиква + гротеск».
- ★ **Широкий гротеск капсом для каждого заголовка** (Unbounded 900 в 7 из 11) → характер шрифта от темы (узкий техно, книжная антиква, моно для кода).
- ★ **Моно-шрифт для микроподписей «как терминал»** (11 из 11) — главный носитель фальшивого HUD → моно только для настоящего кода на экране.
- **Мелкий капс с разрядкой** (кикер, рубрика, «MOTION DESIGNER») · `dom` → обычный регистр или убрать.
- **Курсив-антиква внутри гротескной строки** («в *вашем* голосе») → одно семейство, выделение размером.
- **Ровные кегли ×1,5** → скачок ×3–×5 (гигантское слово рядом с мелкой подписью), контраст начертаний 100–200 против 800–900.
- **Трекинг по умолчанию на крупном кегле** → −1,5…−5 % em на заголовках.
- **Гигантское слово-слайд или обрезанное краем в каждом ролике** — «вторичный шаблон» (так модель «чинит» слайды) → крупный масштаб один раз и с причиной.
- **Заголовок печатается по буквам с кареткой** · по сюжету тоже → слова целиком с шагом 2–5 кадров; печать — только в настоящем поле ввода или как осознанный фирменный жест один раз за ролик.

## 3. Композиция
- ★ **Хук-раскладка: капс-заголовок сверху слева, предмет по центру, пустой низ** (8 из 10) → начать с действия в середине или крупного плана детали; текст на предмете или в мире.
- ★ **Пустой низ кадра** (6 из 11) → в нижнюю треть — передний план (руки, стол, край предмета), с учётом зоны интерфейса площадки.
- ★ **Шапка с моно-рубрикой + линейка; подписи по углам; «ЭКСТРЕННЫЙ ВЫПУСК · ТРЕК 1»** — фальшивый HUD (4 из 11) · `dom` (corner, caps, meta), `code` (counter-label, meta-text) → без рубрик и углов; контекст — одним настоящим объектом.
- **Вёрстка-слайд**: заголовок слева, серый подзаголовок, картинка справа; надзаголовок → одна строка или фраза, вторая половина которой — объект.
- **Тур по функциям**: карточка + подпись × N на одной высоте, равные биты → одно доказательство; биты разной длины.
- ★ **Предмет-герой всегда по центру на ровном фоне** («продуктовый слайд», 6 из 11) → герой в среде, с обрезкой краем и масштабом рядом.
- **Маленькая карточка в пустоте** (< 25 % кадра дольше 1 с) → главный объект на 60–85 % кадра или обрезан краем.
- ★ **3–5 текстовых слоёв в кадре** (заголовок, плашка, подплашка, сноска, субтитр) · `dom` (layers) → не больше 2 целей чтения.
- **Три одинаковые карточки с иконками, всё по центру с равным весом** → раскладка от содержания, ведущий объект.
- **Призрачный декор**: гигантские слова 3–9 %, волосяные линии, сетки «для глубины» · `dom` (ghost) → не ставить; фактура только из материала темы.

## 4. Движение и тайминг
- ★ **Одна «походка» во всех роликах** (одни пресеты пружин из общего ядра, `pop` с перелётом 8 %) · `code` (доля pop/hop) → характер движения от материала: механика (линейный старт, жёсткий стоп), вес (медленно, тяжело), бумага (рывок + трение); пресеты ролика — в его арт-дирекшн.
- **Пружина/отскок на каждом появлении** · `code` → два режима: тихий (без перелёта) для служебного, громкий — 1–3 момента за ролик, на главные слова.
- ★ **Тряска на каждом ударе** (`shake` до 35 раз за ролик) · `code` → 1–2 раза, разная по оси и силе; или реакция предмета (прогиб, трещина, отскок).
- ★ **Камера всегда плывёт; «паузу оживи наездом»** — «скринсейвер» · `code` (cam), `кадры` (движение > 97 %) → статика «на штативе» чередуется с резкими переносами; дрейф там, где он что-то значит.
- ★ **Метроном событий** (новое каждые 1,5–3 с) · `кадры` (разброс интервалов склеек < 0,35) → рваный ритм по смыслу: 3 с на одном кадре → 4 склейки за секунду.
- ★ **Всё строго «на слово»** (караоке-презентация) → часть событий с опережением 0,3–0,5 с или как реакция после слова, часть без привязки к голосу.
- **Одна кривая на всё; симметричный ease-in-out** · `code` → своя кривая на роль: вход — мягкая посадка, выход — ускорение за 6–13 кадров.
- **Одинаковый стаггер** (равный шаг, одинаковый въезд 24 px + blur) → неравные интервалы (3,2,2,2 кадра), разная механика у слов строки.
- **Застывшие паузы «подержал и заменил»** · `кадры` (> 0,6 с) → настоящая пауза только после развязки, 0,5–1 с; на удержании что-то живёт.
- **Демонстрация техник**: каждый бит — новый эффект → одна идея, сквозной мотив.
- **Выход — вход наоборот** → выход быстрее, с ускорением, перекрывает следующий вход на ~2 кадра.

## 5. Появления и декор
- **Проявление по прозрачности 0 → 1** → слово целиком за кадр или въезд со сдвигом 3–24 % высоты.
- **Предметы прилетают из-за кадра на места; логотип вырастает из нуля** → масштаб на месте 0 → 1,12 → 1; логотип входит увеличенным и размытым.
- ★ **Штамп-вердикт с поворотом и ударом** («ОТКАЗАНО», «ДОСТУП ЗАКРЫТ», 6 из 11) · `code` (stamp) → показать последствие (дверь не открылась, загрузка встала).
- ★ **Скотч, оградительная лента** (4 из 11) · `code` (tape) → только если объясняет, один раз.
- ★ **Обвести красным, прицел** (5+ из 11) · `code` (circleMark) → указать действием: курсор, крупный план детали, остальное в серый.
- ★ **Красное зачёркивание «не X», «≠»** (6 из 11), пара к речевому «Не X. Он Y» · `code` (strike) → два варианта рядом, пусть зритель увидит разницу.
- ★ **Маркер под ключевым словом** (7 из 11) · `code` (marker) → одно выделение на ролик, размером или положением.
- ★ **Сквош-«поп» у всех мелких объектов** · `code` (squash) → сквош только у мягкого и живого; металл, стекло, бумага — без перелёта.
- ★ **Мемфис-фигурки, конфетти, солнечные лучи, частицы** · `code` (confetti) → каждый объект кадра — из темы.
- **Первая ассоциация** (запуск = ракета, безопасность = щит) · `глаз` → записать первую идею и отказаться; одна правдивая деталь из темы.
- **Типовая UI-карточка** («Доброе утро», «Выручка · 12 400», точка статуса, три кружка) · `code` → увеличенный фрагмент настоящего интерфейса, обрезанный краем.
- **Эмодзи вместо иконок** · `code`, `text` → один набор иконок или настоящая иконка продукта.
- **Стекло (glassmorphism)** · `code` → плоская карточка.

## 6. Переходы и камера
- ★ **Крэш-зум с размытием на каждом переходе** (5 из 11) · `code` (crash/whip) → склейка встык по действию (вылетел из кадра → влетел в следующий), match cut по форме.
- **Наплыв двух текстов** → жёсткая склейка посреди движения с общим объектом.
- **Белая вспышка / провал в чёрное между битами** · `кадры` → растущий объект; вспышка — максимум на 1–2 главных ударах.
- **Сцена начинается с покоя** → первый кадр уже в движении по вектору прошлой сцены.
- **Медленный плавный зум по умолчанию** → рывок за кадр и хвост 9–18 кадров; толчок за 2 кадра.
- **Телефон/карточка наклонены в 3D на 15°** · `code` → обрезанное устройство в нескольких удержанных позах.
- ★ **Петля финал → хук в каждом ролике** (4 из 11; в Opus-корпусе — копируемая формула) → оставить, но не всегда.

## 7. Числа и данные
- ★ **«Большое число + ярлык капсом + мелкая сноска»** (stat card, 7 из 11) — самый узнаваемый блок ИИ-инфографики · `dom` (stat) → число вшить в предмет (ценник, табло, гравировка, весы с гирями, стопка).
- ★ **Число докручивается / одометр** (5 из 11) · `code` (count) → число предметом; счётчик максимум один на ролик, итог некруглый.
- ★ **Микросноски с источником мелким текстом** (6 из 11) · `dom` (tiny) → источник голосом одним словом («по данным Sony») или в описании.
- **Веб-график в видео** (легенда, две оси, Chart.js) · `code` → 2–3 метрики, рисованный SVG, подписи у данных.
- **Палитра графиков по умолчанию** (matplotlib, Tailwind-радуга) · `code` → серый + 1–2 выделенные категории.

## 8. 3D
- ★ **Продукт на бесшовном цветном фоне со студийным HDRI и мягкой тенью** — пастиш рекламы Apple → предмет в руке или в настоящей среде, блики от реального окна.
- ★ **Игрушечный пастельный мир** (клетчатый пол, облака-подушки, пальмы-веера) — частый вид ИИ-3D 2025–26 → мир по референсу эпохи и места; вес и физику оставить.
- **«Пластик»**: глянец, ровный фронтальный свет → шероховатость, немного SSS, направленный свет.
- **3D «для глубины» без причины; 3D-столбики и пирог** → 2D, 3D только если идея физическая.

## 9. Звук
- ★ **Сток, подобранный скриптом по темпу и громкости** (11 из 11) → трек выбирает автор из 2–3 по настроению; нишевые библиотеки или 2–3 звука-лупа темы.
- ★ **Только голос + музыкальная подложка, шумов нет** (5 из 11) → 6–12 записанных звуков на 20 с, привязанных к событиям.
- ★ **Один набор «вжух / поп / дзынь / отказ / бум»** на склейках и «нет» → звуки физики предмета (металл, стекло, бумага, механика), без UI-звуков и вжухов между сценами.
- ★ **Ритуал «обрыв музыки + бум» перед кульминацией** (4 из 11) → тишина там, где смысловой удар, и не в каждом ролике.
- **Звук-обои**: один луп на одном уровне, щелчок на каждом слове → музыка меняется на повороте; 1–3 выбранных удара.
- **Аудиовизуализация как декор** (эквалайзер, спектр) · `code` → звук задаёт время и силу, вид — от темы.

## 10. Текст сценария
Русские маркеры с регулярками — `text.mjs`; пары «было → стало» — `refs/research/human-writing.md` рабочей папки.
- ★ **«Но» на 3–4-й фразе и ещё раз ближе к концу** (10 из 11) — одна мелодия серии · `text` → повороты встык новым фактом, в разных местах; один ролик без «но».
- ★ **Тире как главный знак** (52 % фраз), кульминация «X — и Y» · `text` → половину тире заменить точкой: «Поменял цифру. Ролик пересобрался».
- ★ **Анонс с двоеточием** («И самое странное:», «Вот подвох:», «Причина —») · `text` → сразу факт.
- ★ **«Не X. Он Y» / «это не просто X — это Y»** — фирменная конструкция Claude · `text` → прямое утверждение.
- ★ **Мотив «одна X → большой эффект»** (7 из 11) · `text` → точная величина.
- ★ **Риторический вопрос с ответом сразу** · `text` → максимум один, лучше вопрос персонажа.
- ★ **Превосходные «самый/самое»** (6 из 11) · `text` → конкретная мера.
- ★ **Финал-дилемма «Так это X — или Y?»** (с весами на экране) · `text` → мнение от первого лица или финал на голом факте.
- ★ **«Перешли тому, кто…» дословно** · `text` → менять адресата и глагол или убрать.
- **Слоганы и тройки** («Быстро. Точно. Твоё.», «Встречайте», «бесшовный») · `text` → фраза голосом автора.
- **Фраза подходит к любой теме** (нет числа, имени, предмета) · `глаз` → деталь, которая есть только в этой теме.
- **Хуки-клише** («Вы не поверите», «В этом видео…», «Смотри внимательно») · `text` → событие или заявление с числом в первую секунду.
- **Текст на экране дублирует голос** → на экране ключевое слово или число.
- **Выдуманные цифры, «исследования показывают»** → источник в сценарии, проверка фактов.

## 11. Голос
- **Ровная интонация клона/TTS, один контур у всех фраз, вдохи через равные интервалы** → живая запись по листу записи (↘/→, паузы), с реакциями («да ладно», смешок) и неровным темпом.
- **Скачки тембра на стыках дублей, свист «с/ш»** → диэссер, подбор дублей.

## 12. Субтитры и плашки
- ★ **Субтитр-караоке одного модуля во всех роликах** (одна гарнитура 800, по левому краю, несказанные слова серым 0,46, прыжок слова ×1,07; 9 из 11) — вид авто-субтитров CapCut · `code` (captions) → субтитры как часть вёрстки ролика (на предмете, в мире, разного размера) или крупные ключевые слова вместо полной расшифровки; вид — в арт-дирекшн ролика.
- **Пресет «Хормози»** (по слову, жирный капс, 3 цвета, эмодзи) → одно семейство, один цвет на одно слово фразы.
- ★ **Плашки-ярлыки капсом на каждую мысль** (4 из 11) → 2–3 ярлыка на ролик.
- ★ **CTA в нарисованном поле ввода «НАПИШИ СЛОВО →»** (3 из 11) → призыв голосом и живым жестом (рука с телефоном, реальный экран комментариев).
- **Текст исчезает раньше, чем прочитан** → держать ≥ max(0,8 с; 0,3 с × слова).
- **Текст мельче ~2 % высоты кадра** · `dom` (tiny) → крупнее или в описание.

## 13. Финал и обложка
- **Финал как подвал сайта** (логотип + слоган + кнопка + URL, неподвижный хвост > 1,4 с) · `кадры` (tail) → финал посреди движения, удержание 0,6–1,4 с.
- **Цепочка «X превращается в Y, а Y в логотип»** → только если это идея ролика.
- **ИИ-обложка** (синтетическое сияние, стоковый вид) → стоп-кадр самого ролика, читается при ширине 300 px.
