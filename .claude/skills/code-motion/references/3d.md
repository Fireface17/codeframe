# 3D-слой: three.js под SVG

Содержание: 1. Когда брать · 2. Подключение для `file://` · 3. Холст под SVG · 4. API `gl.js` ·
5. Детерминизм · 6. Морфы форм · 7. Рендер и проверка · 8. Постобработка и текст · 9. Стиль

## 1. Когда брать

3D — для того, чего SVG не умеет: объём, свет, тысячи частиц, город из кубиков, морф тела. Графика
и типографика по-прежнему в SVG. Цена — рендер примерно в 4 раза медленнее SVG (headless рисует WebGL
программно) и отдельная проверка детерминизма. Для быстрого режима (≤3 ч) 3D не бери.

## 2. Подключение для `file://`

Страницу рендер открывает с `file://`, а ES-модули оттуда не грузятся (CORS). Два рабочих пути:

- **Пин `three@0.170.0` + обёртка CJS** (так делает `new_project.sh --3d`). 0.170.0 — последняя версия с
  полной CJS-сборкой: с r171 `build/three.cjs` — заглушка на ~600 байт, и обёртка молча даёт пустой `THREE`.
  ```bash
  npm i -D -E three@0.170.0
  node tools/three_vendor.mjs        # (function(){var exports={};var module={exports};  + build/three.cjs +
                                     #  ;window.THREE=module.exports;})()  -> js/vendor/three.js
  ```
  `three_vendor.mjs` проверяет, что сборка полная, и остановится на заглушке.
- **Любая версия и аддоны** (GLTFLoader и др.) — сборка esbuild в IIFE:
  ```js
  // entry.js
  export * from 'three';
  export { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
  ```
  ```bash
  npx esbuild entry.js --bundle --format=iife --global-name=THREE --outfile=js/vendor/three.js
  ```

Порядок в `index.html`: … `cast.js` → `vendor/three.js` → `gl.js` → `film.js` → `preview.js`.
Вариант «importmap + флаг `--allow-file-access-from-files`» работает в рендере, но ломает превью по
двойному клику — не бери.

## 3. Холст под SVG

- `<canvas id="gl">` — первый ребёнок `#root` (absolute, z-index 0); SVG над ним (`#root > svg` —
  relative, z-index 1, правило уже в `css/style.css` шаблона).
- **В 3D-сценах фон SVG прозрачный**: прячь «бумагу» (прямоугольник фона) на время 3D-сцены, иначе
  холста не видно. Фон кадра в 3D-сцене задаёт `clear` сцены.
- Текст, субтитры и HUD всегда в SVG: там они чёткие и проверяются `safecheck`.

## 4. API `gl.js`

```js
GL.scene('city', ({ THREE, R, W, H, hash01 }) => {        // строится один раз, при первом draw
  const scene = new THREE.Scene(), cam = new THREE.PerspectiveCamera(42, W / H, 0.1, 300);
  /* геометрия, свет, сиды частиц через hash01 */
  return (lt, p) => { /* выставить всё из lt и p */ return { scene, camera: cam, clear: '#f4f1ea' }; };
});
// в frame(t):
if (cur.k === 'city') GL.draw('city', t - cur.t0, { k: prog(t, cur.t0, 3, ease.inOut) });
else GL.clear('#ffffff');                                 // нет 3D в кадре: один clear с кэшем по цвету
```
Настройка рендерера (в `gl.js`): `new THREE.WebGLRenderer({ canvas, antialias: true, preserveDrawingBuffer: true })`,
`setPixelRatio(devicePixelRatio)` (1, при `SCALE=2` — 2), `setSize(W, H, false)`. **Без `preserveDrawingBuffer`
скриншот CDP может снять уже очищенный буфер** — пустые кадры. Пример сцены `orb` (морф шар → мягкий тетраэдр,
светлый фон) лежит в `gl.js`: `GL.draw('orb', t - T.s3, { m, s })`.

## 5. Детерминизм

- `R.render()` — синхронно внутри `frame(t)`. Без `requestAnimationFrame`, `THREE.Clock`, `mixer.update(dt)`
  (для анимаций glTF — `mixer.setTime(t)`).
- Сиды частиц — `hash01(i, seed)` при построении; `Math.random` нельзя.
- Кэш по входам допустим (геометрия морфа пересчитывается только при смене параметров), накопление
  состояния между кадрами — нет.
- **Время в шейдере — от начала сцены** (`uTime = t − scene.t0`), не абсолютное. Иначе спираль частиц
  «наматывается», и при новом голосе (другие `t0`) сцена выглядит иначе.
- Прятать объект — масштабом 0.001 или `visible = false`, не удалением из сцены.
- Проверка: `node render.mjs det out/det <t,t,...>` на тяжёлых моментах — кадры двух прогонов побайтно равны.

## 6. Морфы форм

Жёсткий максимум `max(dot(n, fᵢ))` по граням даёт острые рёбра и мерцание нормалей на сгибе. Бери мягкий
максимум `log(Σ exp(k·dᵢ)) / k` (k ≈ 9, `GL.softMax`) и плотную сетку (`IcosahedronGeometry(1, 72)`), нормали
пересчитывай только при смене параметра морфа.

## 7. Рендер и проверка

- Без GPU-флагов headless рисует WebGL программно: медленно (≈×4 к SVG), зато стабильно и одинаково
  на любой машине. Ориентир: 51,5 с, 1920×1200, 30 fps, 16 подкадров — 632 с на 6 воркерах.
- `--use-angle=metal` (macOS) быстрее, но перед финалом проверяй `render.mjs det`.
- `render.mjs bench` — мс на подкадр в 3D-сценах до полного рендера.
- Цвет сверяй по листу из `render.mjs sheet`, а не по превью в браузере (там аппаратный GPU и свой цвет).

## 8. Постобработка и текст

- NaN в одном пикселе bloom растягивается в чёрный прямоугольник: перед bloom нужен страховочный проход
  (заменить NaN/Inf на 0).
- Кириллица в 3D-тексте — только через typeface, собранный из TTF; проще держать текст в SVG поверх.
  Текст внутри 3D-мира показывай, только если на экране он от 28 px.

## 9. Стиль

Тёмный фон со светящимися частицами — примета ИИ-роликов. Брать только по согласованию с автором;
по умолчанию — светлый фон, матовые материалы, один ключевой свет.
