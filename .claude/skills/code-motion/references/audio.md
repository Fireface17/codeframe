# Звук: голос, тайминги слов, музыка, SFX, сведение

Содержание: 1. Главное · 2. Голос: выбор движка · 3. Голос: производство (+ темпы речи) ·
3б. Живой голос автора · 4. Тайминги слов · 5. Музыка · 6. Звуковые эффекты · 7. Сведение и громкость ·
8. Лицензии · 9. Грабли

Точные команды и параметры скриптов — `scripts/voice/README.md` и `scripts/audio/README.md`.

## 1. Главное

- **Ты не слышишь.** Всё проверяй метриками (распознавание, темп, LUFS, пики, дакинг), а
  итог отдавай человеку на слух с путями к файлам. Никогда не пиши «звучит хорошо».
- Голос задаёт тайминги всего ролика (cues от слов) — делай его рано, параллельно с
  каркасом, на оценочных таймингах.
- Записанное лучше синтезированного: и для SFX, и для музыки.
- Варианты дешёвые: одна анимация — несколько голосов/дорожек (`build.sh` на каждый).

## 2. Голос: выбор движка (бесплатно, локально, Mac M-серии)

| Язык | Движок | Лицензия | Сильные стороны | Слабые |
|---|---|---|---|---|
| EN | Kokoro-82M (`am_michael`, speed 1.1–1.2) | Apache-2.0 | спокойный уверенный диктор, быстро | только en/es/fr/… без русского |
| RU и др. | **Chatterbox Multilingual V3** (голос `default`) | MIT (+ неслышимый водяной знак PerTh) | 0 ошибок распознавания, термины «как есть» (After Effects), ~3 сл/с | без регулировки темпа; «Claude» иногда «Код» — 2–3 дубля |
| RU | Qwen3-TTS 1.7B VoiceDesign (MLX) | Apache-2.0 | голос задаётся описанием («энергичный техноблогер»), самый натуральный дубль | медленный (~2 сл/с, нужно ×1,2–1,25), тембр плавает между дублями, ударения не управляются |
| RU | Supertonic 3 | OpenRAIL-M (контент помечать как ИИ) | стабильный, быстрый | ровная интонация |
| RU | Silero v4/v5 | CC BY-NC-SA (некоммерческая!) | хорошие ударения | латиницу молча выкидывает; не для монетизации |
| RU | edge-tts (Dmitry/Svetlana) | неофициальный доступ к Microsoft | качество | может сломаться (403), прав нет |

Платные с аккаунтом (ElevenLabs и аналоги) — только по решению пользователя.
**Живой голос** пользователя часто лучше любого синтеза для соцсетей: предложи записать
(диктофон, 15–20 см от рта, тихая комната с мягкими вещами, несколько дублей подряд в одном
файле) — конвейер записи в §3б, дальше та же цепочка выравнивания.

**«Живость» Chatterbox:** `exaggeration` 0.5 (спокойно) → 0.75 (живо) → 0.9 (драматично);
при высокой экспрессии `cfg` 0.3–0.4 держит темп; `temperature` 0.8–0.9. Метрики живости:
разброс высоты тона (σF0, полутоны), диапазон F0, разброс громкости по словам.

## 3. Голос: производство

1. `script.json` (см. `references/storyboard.md`): `display` / `tts` / `align`.
   - одиночные буквы прописью в `tts` («двигаю тэ»), на экране остаётся «t»;
   - ударения: RUAccent (U+0301) — «перелёт», «поса́дка», «ро́лик»; проверь проблемные;
   - для выравнивания термины кириллицей: «Афтер Эффектс», «Клод».
2. Синтез: 3–4 дубля на фразу (разные seed), каждая фраза отдельно.
3. Отбор: распознавание whisper large-v3-turbo (WER по `align`), темп по таблице ниже,
   нет клиппинга и обрезанных хвостов; при равенстве — живость.
4. Склейка: тишина 0,3 с в начале, паузы по звучанию 0,28–0,32 с между фразами (после
   запятой внутри мысли — 0,15), 0,6 с в конце; фейды 5 мс; −16 LUFS; TP ≤ −1,5 dBTP.
5. Выравнивание слов → `audio/vo/words.json` (экранные слова) → `node tools/timing.mjs`.

Команды из папки проекта (подробности и все флаги — `scripts/voice/README.md`):
```bash
V=~/.claude/skills/code-motion/scripts/voice
uv run --script $V/tts_chatterbox.py --script script.json --out audio/vo/takes --seeds 7,11,13,17 --stress   # en: tts_kokoro.py --voice am_michael --speed 1.1
uv run --script $V/check_takes.py --script script.json --takes audio/vo/takes --out audio/vo/picks.json
uv run --script $V/assemble.py --script script.json --picks audio/vo/picks.json --out audio/vo/vo.wav
uv run --script $V/align.py --script script.json --wav audio/vo/vo.wav --out audio/vo/words.json
node tools/timing.mjs && zsh tools/build.sh v2
```
Живее: `--exaggeration 0.75 --cfg 0.35 --temperature 0.85`. Несколько голосов — несколько
`vo.wav`/`words.json` и `build.sh` на каждый (теги `v2a`, `v2b`…). Первый запуск качает модели
(~7–8 ГБ в `~/.cache/code-motion/`).

**Бюджет:** 6 фраз × 3–4 дубля — 15–30 минут. Субагенту прямо пиши предел; без него он
легко уходит в сотни дублей.

**Темпы речи (русский; единая таблица — остальные справочники ссылаются сюда):**

| Что | Слов в секунду |
|---|---|
| Синтез (Chatterbox, Kokoro `--speed 1.1`) | 2,8–3,3 |
| Живая запись, как прочитано | 2,1–2,5 |
| Живая запись после обработки (паузы ×0,7, темп до +8 %) | +6–8 % к записи |
| **Планировать сценарий** | **2,5–3** (объясняющий ролик 35–55 с — 120–160 слов) |

Английский — примерно на 10 % больше слов за то же время.

## 3б. Живой голос автора

**Текст для записи** `<slug>.zapis.md` рядом со сценарием: главное слово каждой фразы КАПСОМ, паузы `|`,
интонация `↘` (утверждение) / `→` (мысль продолжается), ударения в трудных словах, памятка перед записью.
Запись — 3 прохода всего текста (или по 2–3 дубля каждой фразы подряд), ~2,5 сл/с, диктофон или ноутбук,
15–20 см от рта, тихая комната с мягкими вещами.

**Конвейер** (команды — `scripts/voice/README.md`, раздел «Живой голос»):
1. `takes.py` нарезает запись на дубли: куски речи по энергии, распознавание каждого куска (mlx-whisper),
   сопоставление с фразами `script.json`.
2. Если запись вразброс (повторы не подряд, поправки, сбои): `live_words.py` (слова с таймингами) +
   `live_cut.py spans.json` — дубль задаётся отрезком слов, сбой обходится склейкой двух кусков. Стыки — по
   тишине (окно 20 мс ниже −55 дБFS): тайминги mlx-whisper сдвинуты на 0,2–0,35 с.
3. `check_takes.py` (текст) + `prosody.py` (σF0, спад тона в последние 0,4 с, паузы внутри дубля). Порядок
   выбора: текст дословно → интонация как в тексте для записи (конец ↘, не вопрос) → живость → темп.
   Подсказка whisper (`initial_prompt`) распознавание не исправляет, ударения он не слышит — их слушает человек.
4. `live_chain.py` — «цепочка C»: pregain до ≈ −20 LUFS, ФВЧ 80 Гц, adeclick, afftdn nr=10, EQ −3@120 /
   −6@330 / −2@560 / +3@2k / +3@3,5k / +3 полка 9k, экспандер, компрессор 3:1. Вдох срезается (начало не раньше
   0,17 с до звонкого звука), паузы между фразами ×0,7, длинные внутренние — до ~0,28 с, темп до +8 % без смены высоты.
5. `deess.py --pct 90 --max 6` → −16 LUFS + лимитер −2 dBFS → `align.py` → `node tools/timing.mjs`.
Одну фразу можно заменить без пересборки: `patch_phrase.py` (та же цепочка, подгонка длины, кроссфейд 15 мс).
Клон голоса автора — только для проб и черновика; в публикацию — по решению автора.

## 4. Тайминги слов

- Whisper word timestamps — грубые (MAE ~126 мс, ранний старт): для синхрона не годятся.
- **Forced alignment по известному тексту** (wav2vec2 CTC; ru — `jonatasgrosman/wav2vec2-
  large-xlsr-53-russian`) — MAE начала слова ~22 мс. Плюс доводка: начало фразы по
  слышимому звуку, конец слова = начало следующего или начало паузы, короткие слова
  («Я», «тэ») — по энергии.
- Kokoro даёт длительности фонем сам — для EN можно брать их (сдвиг −25 мс).
- Формат `words.json`: `{ duration, phrases: [{ i, start, end, text }], words: [{ w, start, end }] }`,
  `w` — слово как в субтитрах; число слов = число слов `display` в `script.json`.

## 5. Музыка

- Где: Mixkit (Free License, без указания автора, соцсети и коммерция — да; нельзя
  распространять сами файлы), Pixabay Music, CC0. Скачивать в проект (`audio/music/`).
- Выбор без прослушивания (`scripts/audio/analyze.py`, `vocal_check.py`):
  - темп: explainer 90–115 BPM, рилс 110–125;
  - лад по хроме: мажор для дружелюбного тона (название трека может обманывать);
  - мягкость: доля энергии выше 4 кГц (1–3 % — мягко), crest-фактор ударных;
  - ровность сетки (отклонение ударов в мс) и стабильность громкости;
  - вокал: whisper не должен распознавать слова;
  - есть ли спокойное вступление (explainer) или энергия с первой доли (рилс).
  Отобрать 6–10 кандидатов, оставить основной + 2 запасных, назвать человеку.
- Под длительность:
  - **петля** (`loop.py`): целые такты (6–12), подгонка темпа до ±7 % без смены высоты,
    старт на сильной доле без фейда, конец на тактовой черте, шов проверяется численно.
    Короткий ролик (< ~10 с) может не уложиться в целые такты: `build.sh` пробует ±15 %,
    а затем берёт естественную концовку и пишет об этом. Тогда либо смени трек (другой
    темп), либо подгони длительность ролика под такт (`D = n · 60 / BPM · 4`);
  - **концовка** (`edit.py`): спокойное начало трека, естественный финальный аккорд на
    тактовой черте или затухание 1,5–2 с на тонике, кончающееся ровно с роликом;
  - **с дропа** (энергичный монтаж): музыка стартует не с интро, а с сильного такта после
    нарастания — склейка из чёрного прямо на долю, без fade-in; конец трека совпадает с концом ролика.
    `bars.py трек.wav` → такт, где громкость прыгает → `edit.py трек.wav out/music.wav D --start-bar N
    --fade-in 0 --end auto`, или вручную `--plan 0:D:<секунда доли в треке> --fade-from <D − 1,2>`.
    В `build.sh`: `MODE=edit EDIT_ARGS="--start-bar N --fade-in 0"` (или `EDIT_ARGS="--plan 0:D:25.9"`,
    `:D:` подставится), готовая ручная нарезка — `MUSIC_CUT=out/music_drop.wav` (её build.sh не трогает).
    **Первая сильная доля — на первой склейке**, остальные ключевые склейки — на сильные доли из
    `music.plan.json` (поле `beats`, `downbeat: true`).

## 6. Звуковые эффекты

- `assets/sfx/` — записанные физические звуки CC0 (Kenney): `hit` (деревянный стук), `thud` (мягкий
  тяжёлый удар), `paper` (книга/карта легла), `whoosh` (воздух), `scribble` (росчерк), `boom` (низкий
  «бум»), `mech` (металлическая защёлка). whoosh_1/2 и scribble — приближения из foley-шумов (на слух не
  проверены — при сомнении замени Mixkit-звуками). Mixkit SFX (мягкие whoosh, ручка по бумаге) — скачать
  в проект и подготовить `scripts/audio/sfx_make.py`, передать `--sfx-dir`.
- Сколько: 6–12 на 20 секунд; не каждое появление — каскад озвучь 2–3 звуками; не больше одного
  звука за 0,1 с; повторяющиеся — тише и с ротацией вариантов (`hit` → `hit_1..N`).
- Где: появление (стук, бумага), переключатель (mech), рисование линии (scribble), перелёт камеры
  (мягкий воздушный whoosh без тона), финальный акцент (thud, на главном ударе — boom).
- **Не брать:** pop, ding, свистящие свипы (`maximize/minimize` из Kenney Interface), писк, «бульк» —
  на слух они детские и мультяшные. Если звук с тоном или свистом — заменить или убрать
  (`sfx_analyze.py` помечает устойчивый тон как `TONE`; свип смотри по спектрограмме).
  Стоит выбор, звук или тишина, — бери тишину.
- **Длина звука ≤ промежутка до следующей склейки.** Библиотечные звуки бывают по 2–5 с: хвост глитча,
  тянущийся через следующую сцену, звучит посторонним. Режь при подготовке (`sfx_make.py --spec` с
  `maxdur`/`fout`). Ориентиры: удар 0,4–0,7 с, whoosh 0,4–0,5, «бум» до 2. Фильм выставляет
  `window.CUTS = [...]` (времена склеек) — `render.mjs events` кладёт их в `events.json`, и `mix.py`
  предупреждает о каждом звуке, заходящем за следующую склейку.
- В `film.js`: `sfx(T.x, 'hit', -8)` → `window.SFX_EVENTS` → `render.mjs events`.

## 7. Сведение и громкость

`mix.py <music|-> <vo|-> events.json out.wav [--no-music] [--lufs -14]`:
- музыка уходит под голос на ~9 дБ (атака 80 мс, релиз 400 мс, упреждение 80, удержание
  120 — не дёргается в паузах между словами);
- SFX по уровню голоса −6 дБ, в общей маленькой «комнате» (не звучат наклеенными);
- итог: −14 LUFS (соцсети) или −16 (explainer, обычно с `--bed-rel -5` — музыка тише голоса
  на 5 LU), TP ≤ −1 dBTP; ролик без голоса со спокойной музыкой можно свести на −18
  (по ощущению равно речи на −16);
- без голоса (`-` вместо vo) опорой для SFX служит музыка, дакинга нет;
- проверка: `ffmpeg -nostats -i mix.wav -af ebur128=peak=true -f null - 2>&1 | grep -E "^ +(I|Peak):"`.
- **Баланс голос − музыка под речью:** объясняющий ролик — 13–15 LU (по умолчанию); энергичный монтаж
  под бит — 5–7 LU (`mix.py --bed-rel -1.5 --duck 5`; в `build.sh` — `MIX_ARGS="--bed-rel -1.5 --duck 5"`).
  `mix.py` печатает фактическое «voice-music … LU» — сверяй с целью.
- Без голоса и без музыки (только SFX, например демо шаблона) звуки ставятся против условного голоса
  −16 LUFS, громкость не нормализуется.

## 9. Грабли

- Chatterbox на 16 ГБ уходит в своп на длинном тексте → лимиты MPS
  (`PYTORCH_MPS_HIGH_WATERMARK_RATIO=0.8`, `LOW=0.6`; скрипты ставят сами); фразы по одной.
- Дубль, первый по метрикам, в склейке прозвучал как другое слово («перейдёт» вместо
  «перелёт») → проверяй распознаванием уже собранный файл, а не только дубли.
- Whisper пишет «с двигом» вместо «сдвигом», «кот» вместо «код» в конце фразы — это
  особенности распознавания, не синтеза; не гоняйся за ними.
- Пик синтеза бывает выше 0 dBFS → храни float32 до финальной нормализации.
- Ducking стартует с задержкой атаки: голос лучше начинать не раньше 0,3 с.
- Для чистого шва петли голос заканчивается за 0,5 с до конца.
