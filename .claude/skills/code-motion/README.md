# code-motion — моушн-дизайн кодом с Claude

Навык (skill) для [Claude Code](https://docs.claude.com/en/docs/claude-code): ТЗ, сценарий, макеты или просто идея
превращаются в готовый MP4 — explainer, кинетическая типографика, рилсы, шортсы, TikTok, промо, анимированные схемы и
интерфейсы. Каждый кадр — чистая функция времени `frame(t)` на HTML/SVG (по желанию — со слоем three.js); headless
Chromium снимает кадры с motion blur, ffmpeg собирает видео. В комплекте: движок с пружинами и рисующимися линиями,
синхрон анимации со словами озвучки, нейроголос и конвейер живого голоса, подгонка музыки по тактам, сведение со
звуками, автопроверки (безопасные зоны, рывки, шов петли, громкость).

Инструкции для Claude — `SKILL.md` и `references/`; люди могут читать их как справочник.

## Установка

```bash
git clone <этот репозиторий> ~/.claude/skills/code-motion
```
Claude Code подхватит навык сам: попросите «сделай анимацию …», «рилс про …», «анимируй по ТЗ». Если навык лежит в
другой папке, укажите её проектам: `export CODE_MOTION_SKILL=/путь/к/code-motion`.

Быстрый старт без Claude:
```bash
zsh ~/.claude/skills/code-motion/scripts/new_project.sh ~/films/demo --size 1080x1920
cd ~/films/demo && open index.html               # превью
SUB=4 node render.mjs video out/draft.mp4 6      # черновой рендер
zsh tools/build.sh v1                            # звук, рендер, версии, постер, проверки
```

## Требования

- **macOS на Apple Silicon** — основная платформа: распознавание речи идёт через mlx-whisper, скрипты — на zsh.
  На Linux работают движок, рендер, музыка и сведение (нужен zsh); `check_takes.py` переключится на faster-whisper,
  а нарезка живой записи (`takes.py`, `live_words.py`) требует mlx.
- node 20+ и npm, ffmpeg (со сборкой libx264), [uv](https://docs.astral.sh/uv/) для Python-скриптов,
  Playwright Chromium (`npx playwright install chromium` — `new_project.sh` ставит сам).
- Место: модели голоса и распознавания качаются при первом запуске в `~/.cache/code-motion/` (до ~8 ГБ).

## Что внутри

| Папка | Что |
|---|---|
| `scripts/engine/` | движок страницы: время и пружины, SVG-позы, линии, cues от слов, субтитры, плашки кода, персонажи, 3D-слой |
| `scripts/template/` | стартовый проект: рабочий демо-ролик ~7 с |
| `scripts/render.mjs` | рендер: кадры, листы, видео с motion blur, звук, бенчмарк, проверка детерминизма |
| `scripts/tools/` | тайминги, токены кода, проверки, разбор ТЗ, пипетка, контактные листы |
| `scripts/voice/` | синтез (Chatterbox, Kokoro), живая запись, отбор дублей, выравнивание слов |
| `scripts/audio/` | анализ музыки, петля и нарезка по тактам, сведение, подготовка звуков |
| `assets/sfx/` | физические звуки CC0 (Kenney): удар, бумага, воздух, «бум», механика |
| `references/` | справочники: процесс, движок, язык движения, раскадровка, звук, рендер, проверки, соцсети, 3D |
