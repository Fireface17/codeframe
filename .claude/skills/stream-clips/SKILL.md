# stream-clips — нарезки стримов

Из многочасового стрима — готовые вертикальные клипы 20–60 секунд (1080×1920). Всё рабочее лежит в `tools/stream/`.
Этот файл — точка входа; шаги, форматы и обязательные требования — в `tools/stream/RUNBOOK.md` (читать целиком перед работой).

## Где что

| Что | Где |
|---|---|
| Инструкция монтажёра: шаги, монтажный лист, требования к клипу | `tools/stream/RUNBOOK.md` |
| Поиск моментов | `live.py` (идёт ли эфир), `scout.py` (звук + чат + расшифровка → лента и кандидаты), `top.py`, `storozh.py` (дежурный на идущий эфир) |
| Скачивание записи | `hls.py` (идущую запись качать только им), `gql.py` (чат и клипы Twitch) |
| Сборка клипа | `build.py` (монтажный лист JSON → MP4), `text.mjs` (заголовок, метка, субтитры PNG) |
| Брань | `censor.py` (звук-цензура по интервалам), `bleep.py` (писк с самопроверкой распознаванием) |
| Громкость по окнам (поиск пауз для склеек) | `env.py` |
| Загрузка на площадки через управляемый браузер | `tools/stream/browser/` (`start.sh`, `do.py`, `cdp.mjs`, рецепт — `UPLOAD.md`) |
| Точные времена слов | `code-motion/scripts/voice/align.py --global` (≈20 мс) |

Нужны: `ffmpeg`, Python 3, Node 20+, `whisper-cli` (whisper.cpp) и модель `ggml-large-v3-turbo-q5_0.bin` (`WHISPER_MODEL`
или `library/models/`), для текста на кадре — `cd lab && npm i` и `cd library && npm i`.

## Права и условия

- Нарезай только то, что тебе разрешено: свои стримы или записи стримера, который согласился на клипы. Чужой контент без
  разрешения на платформы не выкладывай; условия Twitch и площадок читай сам — скрипты `hls.py` и `gql.py` обращаются к
  неофициальным интерфейсам Twitch и могут перестать работать. Используй на свой риск.
- Звуки-мемы из YouTube в публичные ролики не клади — права. Берёшь CC0 (`library/sfx/`).

## Главное, что нельзя вывести из кода

- **Звук агент не слышит.** Речь — из расшифровки и чата, склейки — по провалам громкости, времена слов — только из точного
  выравнивания (`align.py --global`). Времена whisper врут до двух секунд: по ним нельзя ставить ни цензуру, ни акценты.
  Об этом ограничении говорить автору прямо и просить проверить на слух.
- **Идущую запись Twitch качать через `hls.py`.** Штатный yt-dlp тянет растущую запись со скоростью эфира.
- **Момент выбирается там, где сошлись всплеск чата и законченная мысль в расшифровке.** Громкость одна ничего не значит.
  Кто говорит и о ком речь — проверять по чату и словам стримера; слабые модели ошибаются (перепутанные роли в заголовке).
- **Правила монтажа** (подробнее — `RUNBOOK.md`): строго по порядку, момент целиком, 20–60 секунд; развязку в начало не выносить;
  лицо крупно; наезд и отъезд на важных словах; звуковых эффектов мало и по ситуации.
- **Мат.** YouTube за плотный мат ставит ролику 18+. В заголовок на кадре мат не идёт даже со звёздочками; ролики с плотным
  матом — в TikTok и Instagram, на YouTube — чистые или с цензурой.
- **Публикация** идёт через отдельный Chromium с сохранёнными входами (`browser/start.sh`) шагами через постоянный сеанс;
  загрузка и «Опубликовать» — в одном сеансе, вкладку студии не бросать на полпути. Каждую публикацию — строкой в журнал.
  Перед правками в студии проверять по адресу, что открыт нужный канал.
- **Раскладка кадра у каждого стримера своя.** Режимы `split`, `zoom`, `game` зашиты под один кадр; для остальных —
  `face`/`stack` с явными областями из монтажного листа (`RUNBOOK.md`, шаг 5в). Сверяй по листу кадров.
- **Расход.** Полный цикл агентом Opus — порядка 135 тысяч токенов на клип.

## Порядок работы

1. Прочитать `tools/stream/RUNBOOK.md`.
2. Данные стрима → кандидаты → выбор момента (шаги 1–2).
3. Видео, границы, черновая сборка, точное выравнивание слов, монтажный лист с приёмами (шаги 3–5б).
4. Проверка по листу кадров и расшифровке результата (шаг 6); по возможности — критик-зритель.
5. Публикация и запись в журнал — только если автор это прямо разрешил в текущей сессии.
