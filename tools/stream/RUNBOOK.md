# Нарезки стримов: инструкция для агента-монтажёра

Ты режешь вертикальные клипы (1080×1920) из стримов Twitch для канала нарезок. Вход — запись стрима
(в том числе идущего). Выход — готовый MP4 20–60 секунд с заголовком и субтитрами. Публикацией ты не занимаешься.

Звук ты не слышишь. Всё, что касается речи, берётся из расшифровки, чата и громкости; картинка — из кадров, которые ты
смотришь через Read.

## Окружение

- Перед командами: `export PATH="/opt/homebrew/bin:$PATH"`. Оболочка — zsh.
- `curl`, `wget`, `rm -rf` запрещены. Сеть — только через скрипты ниже.
- Скрипты: `tools/stream/` репозитория (дальше `K/`). Не меняй их; нужна правка — опиши в отчёте.
- Рабочие файлы клади в свою рабочую папку, которую тебе назвали, — не внутрь репозитория (записи стримов большие).
- Нужны `ffmpeg`, `python3`, `node`, `whisper-cli` (whisper.cpp) и модель `ggml-large-v3-turbo-q5_0.bin` (путь — переменная `WHISPER_MODEL`
  или `library/models/`).

## Шаг 1. Данные стрима

```
python3 K/live.py <логин>                      # идёт ли эфир, id записи, длина
python3 K/scout.py fetch <vod> <a> <b> <work>   # звук и чат отрезка [a,b] секунд записи
python3 K/scout.py transcribe <work>            # расшифровка кусками по 5 мин (≈30× быстрее эфира)
python3 K/scout.py timeline <work>              # timeline.txt (лента по 30 с) и candidates.txt (всплески чата)
```

Строка ленты: `[время ч+1.2 см25% гр+1.8★!] текст`. `ч` — отклонение скорости чата от местной нормы,
`см` — доля сообщений со смехом, `гр` — громкость, `★` — сильный всплеск чата, `!` — всплеск громкости.
`segs.json` — реплики `[начало, конец, текст]` в секундах записи. `chat.json` — выборка чата каждые 10 с с текстами.

Если данные уже лежат в папке — шаг пропусти.

## Шаг 2. Отбор момента

1. Возьми `candidates.txt`. Чат реагирует на 5–20 секунд позже момента: причина всегда раньше всплеска.
2. Для каждого кандидата прочитай ленту от −2 минут до +1 минуты и сообщения чата в эти секунды.
3. Громкость одна ничего не значит. Сильный сигнал — когда чат смеётся или спорит, а в речи есть законченная мысль.
4. Годный момент: понятен человеку, который не смотрел стрим; есть завязка, сам момент и реакция или развязка;
   умещается в 20–60 секунд; в нём шутка, спор, провал, неожиданность или сильная эмоция.
5. Не бери: рекламу и розыгрыши стримера; куски, где смысл в музыке; катсцены игры без реакции стримера;
   моменты, понятные только постоянным зрителям.
6. Кто говорит и о ком речь — проверяй по чату и по словам самого стримера. Не уверен — формулируй нейтрально.

Выпиши три лучших момента: время, одна строка «что произошло», почему чат отреагировал. Лучший — в работу.

## Шаг 3. Видео и точные времена

```
python3 K/hls.py <vod> 1080p60 <a-10> <b+10> <work>/raw.mp4     # печатает start — время начала скачанного куска
ffmpeg -v error -y -i raw.mp4 -c copy -avoid_negative_ts make_zero -reset_timestamps 1 src.mp4
ffmpeg -v error -y -i src.mp4 -vn -ac 1 -ar 16000 src.wav
whisper-cli -m "$WHISPER_MODEL" -l ru -mc 0 -ml 1 -sow -f src.wav -osrt -of words
python3 K/env.py src.wav 18-22 68-72        # громкость по 50 мс в окнах: пауза — провал ниже примерно −45
```

Дальше все времена — в секундах `src.mp4` (время записи минус `start`). Пословные времена неточны на ±0,2 с;
начало и конец куска ставь в провал громкости между фразами, а не по времени слова.

Посмотри кадры: `ffmpeg -v error -y -i src.mp4 -vf "fps=1/5,scale=480:-1,tile=6x3" -frames:v 1 sheet.jpg`, затем Read.
Найди, где вебкамера и что на остальном экране.

## Шаг 4. Правила нарезки

- Строго по порядку. Развязку в начало не выносить, отмоток назад не делать.
- Момент целиком: завязка → момент → реакция. Конец — на развязке или реакции, без хвоста.
- 20–60 секунд. Короче 15 — не клип.
- Внутренних склеек — не больше двух, только в паузах, только чтобы убрать мёртвое место или перебивание.
- Первая осмысленная фраза звучит в первые 1–2 секунды.
- Картинка меняется по смыслу каждые 7–12 секунд (режимы ниже), но не на каждой фразе.

## Шаг 5. Монтажный лист

JSON для `python3 K/build.py <edl.json>`:

```json
{"src": ".../src.mp4", "out": ".../клип.mp4", "work": ".../w",
 "seam_y": 395, "sub_y": 1300,
 "title": ["Строка 1", "Строка 2"], "tag": "STREAMER · twitch",
 "blocks": [{"a": 21.80, "b": 36.25, "parts": [{"to": 28.45, "mode": "talk"}, {"to": 36.25, "mode": "talkzoom"}]}],
 "subs": [{"a": 21.90, "b": 22.50, "text": "Ты говоришь:"}, {"a": 74.7, "b": 75.4, "text": "Ну да...", "color": "#5ce1ff"}],
 "captions": [{"name": "ctx", "text": "Контекст одной фразой", "a": 21.85, "b": 28.40, "y": 1172}]}
```

- `blocks` — непрерывные куски исходника по порядку; `parts` делят кусок по режимам, последний `to` равен `b`.
- Режимы: `talk` и `talkzoom` — разговорный стрим: вебкамера на размытом фоне, обычная и чуть крупнее
  (`seam_y` 395, `sub_y` 1300, подписи `y` 1172). `split` и `zoom` — игра: камера сверху, игра снизу; `game` — игра во весь экран
  (`seam_y` 607, `sub_y` 1270, подписи `y` 770). Геометрия камеры в режимах зашита под одну раскладку
  (камера слева вверху, около 592×333 из 1920×1080). У другого стримера — подгони координаты по листу кадров или используй `face`/`stack` с явными областями (ниже).
- `subs` — по 1–4 слова, время в секундах `src.mp4`, только внутри блоков. Текст вычитай по смыслу: ники, сленг, названия.
  Мат закрывай звёздочкой на месте гласной (`х*йня`, `бл*дь`). Второй голос — `"color": "#5ce1ff"` и подпись, кто это.
  Длинное тире в конце чанка не ставь — оно переносится на отдельную строку.
- `title` — две строки до ~24 знаков: имена и суть конфликта или шутки. Не «смешной момент».
- `captions` — одна-две подписи монтажёра: контекст в начале, смена говорящего.

## Шаг 5а. Точные времена слов, монтажные приёмы, звук

**Точные времена слов.** Времена whisper врут до 2 секунд — по ним нельзя ставить ни акценты, ни цензуру. Сначала собери клип
без приёмов, вытащи из него звук (16 кГц моно) и выровняй по нему вычитанный текст:

```
uv run --script ~/.claude/skills/code-motion/scripts/voice/align.py --script script.json --wav vo.wav --out words.json --global
```

`script.json`: `{"lang":"ru","lead":0.1,"tail":0.1,"pauses":[0.2],"phrases":[{"display":"фраза как звучит, кириллицей, с матом как есть"}]}`.
В `words.json` — начало и конец каждого слова в секундах клипа (точность около 20 мс). Дальше субтитры задаются временами ролика:
`{"text": "я беру и _закуриваю_", "ow": [[26.9,27.0],[27.0,27.3],[27.3,27.4],[27.4,28.6]]}` — по паре на каждое слово.

**Акцент на слове.** Слово в подчёркиваниях (`_закуриваю_`) рисуется крупнее. Одно-два на фразу: то слово, на котором держится смысл.

**Наезд и отъезд.** Режим `talkdyn` у части блока и ключевые точки `"zoom": [[время исходника, масштаб], ...]`; между точками
масштаб меняется плавно. Приёмы: медленный наезд 1.00→1.06 на рассуждении; резкий наезд до 1.16–1.30 за 0,12–0,2 с на вопросе
или панчлайне; отъезд к 1.00 за 0,4–0,8 с на смене мысли или перед новой фразой. Больше 1.30 не брать — мыло.
Не чаще одного резкого наезда на 6–8 секунд.

**Вайн-бум.** Звук берёшь из своей библиотеки (например `library/sfx/` с CC0-звуками); чужие мем-звуки с YouTube в публичные ролики не клади — права. В монтажном листе:
`"sfx": [{"file": ".../hit.wav", "out": 11.55, "gain_db": -9}]` (`out` — секунда ролика). Ставится в паузу сразу после слова,
на котором кого-то поймали, что-то вскрылось или прозвучал панчлайн; вместе с резким наездом. Не больше двух на клип.

**Цензура.** `python3 K/censor.py <клип> <выход> <job.json>`, где `job`: `{"mode":"quack","sample":".../свой_звук_цензуры.wav","words":[[a,b],...]}` —
времена бранных слов только из `words.json`.

## Шаг 5б. Обязательные требования к клипу

Итог разбора двух независимых критиков: первая «улучшенная» версия получила 5 и 5,5 из 10. Всё ниже — их находки.

**Картинка**
- Лицо крупно. Для разговорного стрима — режим `face`: из вебкамеры вырезается область вокруг стримера и ставится окном 1080×1000.
  В монтажном листе: `"face": {"crop": [x, y, w, h], "box_y": 470, "box_h": 1000, "focus": [0.5, 0.38]}`, где `crop` — область
  исходного кадра с соотношением сторон 1,08:1 вокруг лица (например `[69, 8, 360, 333]`), `focus` — точка лица внутри неё.
  Узкая полоса камеры на размытом фоне (режимы `talk`, `talkdyn`) выглядит дёшево: лицо втрое мельче, чем у сильных каналов.
- Положение текста для `face`: `"seam_y": 300` (заголовок), `"tag_y": 492` (метка в углу окна), `"sub_y": 1125, "sub_bottom": true`
  (субтитры на груди, растут вверх, не вылезают за окно), подписи `y` 1150, `"cap_bold": true`.
- Цвет поднимает сам режим `face` (контраст, насыщенность, резкость, тёмный фон) — отдельно не трогать.

**Монтаж**
- Дыр нет. Пауза длиннее 0,7 с вырезается до 0,3–0,5 с. Провал звука до цифровой тишины (в `env.py` ниже −80) — это сбой записи,
  а не пауза: вырезать целиком.
- Повторов нет. Если середина пересказывает начало теми же словами — вырезать, оставить один мост к развязке.
- Речь без субтитров дольше 1,5 с — либо вырезать, либо подписать. Реплики второго человека не «прятать» молча.
- Конец — на законченной фразе или реакции. Проверка: последняя фраза в расшифровке результата не обрывается; ролик не кончается
  на запятой.
- Наезды: медленного «дрейфа» нет. Резкий наезд за 0,12–0,16 с на вопросе или панчлайне; отъезд за 0,15 с на первом слове новой
  мысли. Два главных пика клипа — до 1,22, остальные — 1,10–1,12 (в режиме `face` картинка уже увеличена втрое, больше — мыло).
- После каждой смены состава склеек — заново выравнивание слов (шаг 5а): времена старой версии не годятся.

**Текст на кадре**
- Одновременно не больше трёх блоков: заголовок (две плашки), метка с именами, субтитр. Контекст — в заголовок, а не отдельной
  подписью на первые секунды.
- Заголовок понятен тому, кто не знает стримеров: суть конфликта или шутки, имена — в метке. Пример: «Назвал премию фигнёй — /
  и просит голосовать» вместо «Имя поймал имя / на слове про X». Без мата, даже со звёздочками.
- Метка в углу окна говорит, кто в кадре и кто за кадром: «Стример · на связи гость». Реплики второго человека — другим цветом
  (`"color": "#5ce1ff"`) плюс подпись «отвечает …» ровно с кадра склейки.
- Субтитры без «караоке»: `"karaoke": false` — кусок появляется целиком, цвет несут только акцентные слова. Акцентов не больше
  пяти на клип. Субтитр меняется ровно на склейке и не переходит через неё.
- Первые карточки не должны быть набором звёздочек. Слова, которые состоят из одной брани, в субтитры не выводятся
  (в разметке фраз — прочерк на месте слова), звук при этом не трогается. Название одной вещи пишется везде одинаково (одно написание на весь клип).

**Критики.** Если есть время — один проход критика-зрителя (модель Opus, видит только ролик, до 25 строк, оценки и правки с секундами):
он ловит обрывы, дыры, повторы и непонятность для чужого зрителя, которых автор клипа уже не видит.

## Шаг 5в. Игра с камерой поверх поля (любая игра) — режимы `stack` и `full`

Режимы `split`, `zoom`, `game` зашиты под один старый кадр из шутера — для других игр и раскладок их не брать.
Координаты берутся из монтажного листа:

```json
"layout": {"face": [85, 0, 394, 277], "game": [500, 0, 1005, 1080], "face_h": 760, "focus": [0.5, 0.45], "full": [700, 0, 608, 1080]},
"seam_y": 760, "sub_y": 1270, "tag_y": 36, "karaoke": false
```

- `stack` — лицо крупно сверху (окно 1080×`face_h`), игра снизу. `face` — область исходного кадра вокруг стримера внутри вебкамеры,
  `game` — поле игры без камеры и баннеров, `focus` — точка лица в области `face` (к ней идёт наезд). Наезды — ключевыми точками
  `"zoom"` у части блока, как в режиме `face`, с теми же пределами (пики до 1,22, остальные 1,10–1,12).
- `full` — игра во весь экран (область `full`, вертикальная 608×1080 или с тем же соотношением): для чистого действия, когда лицо
  не нужно. Заголовок в этом режиме скрыт.
- Текст: заголовок — на стыке окон (`seam_y` = `face_h`), метка — в углу окна лица (`tag_y` 36), субтитры — на игре (`sub_y` 1270),
  подписи монтажёра — `y` около 800. На лицо текст не кладётся.
- Соотношение сторон областей подгоняется обрезкой по центру. Раскладку каждого стримера сверь по своему листу кадров: камеру
  могли передвинуть, поверх игры бывают баннеры и подсказки.

## Шаг 6. Проверка

1. `build.py` напечатал `ffmpeg: OK` и длину.
2. Лист кадров результата (`fps=1/2.6,scale=200:-1,tile=10x2`) — посмотри через Read: нет ли чужих полос у камеры,
   читаются ли субтитры, не пусты ли длинные участки.
3. Расшифруй результат whisper-ом (`-otxt`) и сверь с задуманным: первая и последняя фразы целые.
4. Громкость: `ffmpeg -hide_banner -nostats -i клип.mp4 -af ebur128 -f null - 2>&1 | grep "I:"` — около −14 LUFS.
