# tools/stream — нарезки стримов

Конвейер «стрим → вертикальные клипы 20–60 с»: поиск моментов по чату и расшифровке, сборка 1080×1920 с лицом крупно, заголовком и
субтитрами по точным временам слов, цензура, загрузка через управляемый браузер. Работает через навык `stream-clips`
(`.claude/skills/stream-clips/`); пошаговая инструкция — `RUNBOOK.md`, загрузка на площадки — `browser/UPLOAD.md`.

Нужны `ffmpeg`, Python 3, Node 20+, `whisper-cli` и модель `ggml-large-v3-turbo-q5_0.bin` (`export WHISPER_MODEL=…`).
`hls.py` и `gql.py` используют неофициальные интерфейсы Twitch: только свои клипы или с разрешения стримера, на свой риск.
Рабочие файлы (записи, клипы) держи вне репозитория — они большие.
